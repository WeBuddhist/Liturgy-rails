༄༅། །གསུང་ངག་རིན་པོ་ཆེའི་ལམ་རིམ་རྒྱུད་ལ་སྐྱེ་བའི་སྨོན་ལམ་བཞུགས་སོ།།

༄༅། །ན་མོ་གུ་ར་ཝེ།

ཕུན་ཚོགས་དགེ་ལེགས་ཀུན་འབྱུང་དྲིན་ཅན་རྗེ་། །

ཕུལ་བྱུང་མཚན་དཔེའི་དཔལ་འབར་རྡོ་རྗེ་འཆང་། །

ཕས་རྒོལ་ཚར་གཅོད་མཐུ་སྟོབས་དབང་ཕྱུག་ཞབས། །

ཕན་བདེའི་ལམ་སྟོན་རྗེ་བཙུན་ས་སྐྱ་པ། །

བརྒྱུད་པར་བཅས་པའི་མཁྱེན་བརྩེའི་སྤྱན་རས་ཀྱིས། །

བུ་གཅིག་པ་ལ་བརྩེ་བའི་མ་བཞིན་དུ་། །

རྣལ་འབྱོར་བདག་ལ་རྒྱུན་དུ་ལེགས་གཟིགས་ནས། །

ཡིད་ལ་སྨོན་པའི་གནས་འདི་འགྲུབ་པར་མཛོད། །

སྣང་གསུམ་གྱི་མ་དག་པའི་ཉེས་དམྱིགས་ནི།

སྲིད་གསུམ་འཁོར་བ་མཐའ་མེད་འགྲོ་བ་རྣམས། །

སྡུག་བསྔལ་འདུ་བྱེད་འགྱུར་བའི་སྡུག་བསྔལ་གྱིས། །

རྒྱུན་དུ་གཙེས་ཤིང་བདེ་བའི་སྐབས་མེད་པར། །

ངེས་འབྱུང་དྲག་པོ་གཏིང་ནས་སྐྱེ་བར་ཤོག ། (དལ་འབྱོར་རྙེད་དཀའ་ནི། )

ལེགས་བརྒྱས་བསྒྲུབས་པའི་ལུས་རྟེན་ཕུན་ཚོགས་འདི། །

རྙེད་པར་དཀའ་ཞིང་འཇིག་པར་སླ་བ་ཡི། །

རང་བཞིན་རྟོགས་ནས་སྐད་ཅིག་གཡེལ་མེད་པར། །

དལ་རྟེན་ལུས་ལ་སྙིང་པོ་ལེན་པར་ཤོག །

(ལས་རྒྱུ་འབྲས་ནི།)

ཀུན་རྫོབ་འཁྲུལ་པའི་བདེ་སྡུག་སྣང་བ་རྣམས། །

སྔོན་བསགས་ལས་ཀྱི་རྗེས་སུ་འབྲང་བ་ཡི། །

ལས་འབྲས་བསླུ་བ་མེད་པའི་ཚུལ་རྟོགས་ནས། །

དགེ་སྡིག་སྤང་བླང་ཚུལ་བཞིན་བྱེད་པར་ཤོག །

(ཉམས་ཀྱི་སྣང་བ་སྟོན་པ་བྱང་ཆུབ་ཀྱི་སེམས་ནི།)

སྡུག་བསྔལ་རྒྱ་མཚོར་དྲིན་ཆེན་ཕ་མ་རྣམས། །

ལས་ཀྱི་ཆུ་བོ་ཆེན་པོས་ཁེར་མཐོང་ནས། །

བཅོས་མྱིན་བྱམས་དང་སྙིང་རྗེས་དྲངས་པ་ཡི། །

བྱང་ཆུབ་སྨོན་པའི་སེམས་མཆོག་བསྐྱེད་པར་ཤོག །

(འཇུག་པ་བྱང་ཆུབ་ཀྱི་སེམས་ནི། )

ཐེག་ཆེན་ལམ་གྱི་རྩ་བ་ཚུལ་ཁྲིམས་གསུམ། །

བདག་གཞན་མཉམ་དང་བརྩེ་བའི་བྱང་ཆུབ་སེམས། །

ཕ་རོལ་ཕྱིན་དྲུག་བསྡུ་དངོས་བཞི་ལ་སོགས། །

རྒྱ་ཆེན་བྱང་ཆུབ་སྤྱོད་ལ་འཇུག་པར་ཤོག །

(དོན་དམ་བྱང་ཆུབ་ཀྱི་སེམས་ནི།)

རྩེ་གཅིག་གཡོ་བ་མེད་པའི་ཞི་གནས་དང་། །

གནས་ལུགས་འཁྲུལ་མེད་རྟོགས་པའི་ལྷག་མཐོང་གཉིས། །

ཟུང་འཇུག་ཆུ་བོའི་རྒྱུན་ལྟར་བསྒོམས་པ་ཡིས། །

དངོས་འཛིན་འཁྲུལ་པའི་དྲི་མ་སེལ་བར་ཤོག །

(དག་པའི་སྣང་བ་ནི་འབྲས་བུའི་སྐབས་སུ་འབྱུང་བས་འདིར་མ་བཀོད། མདོ་སྔགས་ཀྱི་མཚམས་སྦྱོར་ནི།)

ཕ་རོལ་ཕྱིན་དྲུག་ལམ་གྱིས་རྒྱུད་སྦྱངས་ནས། །

བརྒྱུད་པ་སྐལ་ལྡན་རྒྱུད་དོན་མ་ལུས་རིག །

སྙིང་རྗེར་ལྡན་ཞིང་དམ་ཚིག་མཆོག་སྲུང་བའི། །

རྡོ་རྗེ་སློབ་དཔོན་ཚུལ་བཞིན་མཉེས་བྱེད་ཤོག ། (སྨིན་བྱེད་ཀྱི་དབང་ནི། )དེ

་སོགས་མཚན་ཉིད་ཀུན་ལྡན་བླ་མ་ཡིས། །

རང་ལུས་གཞིར་གནས་དཀྱིལ་འཁོར་རྣམ་བཞི་ལ། །

རྨད་བྱུང་ཆོ་གས་དབང་བཞི་བསྐུར་བ་ཡིས། །

ལམ་བཟང་བཞི་ཡྱི་སྣོད་དུ་འགྱུར་བར་ཤོག །

(དབང་གྱི་དམ་ཚིག་ནི།)

དབང་ལས་ཐོབ་པའི་དམ་ཚིག་སྡོམ་པའི་ཚོགས། །

སྲོག་དང་བསྡོས་ཏེ་ཚུལ་བཞིན་བསྲུང་བ་ཡིས། །

འགལ་རྐྱེན་ཉེས་ཚོགས་མཐའ་དག་རབ་བཅོམ་ནས། །

སྔགས་ཀྱི་ལམ་རྣམས་འགྲུབ་པའི་གཞིར་གྱུར་ཤོག །

(ལྟ་བ་ནི།)

ཕྱི་ནང་དངོས་ཀུན་རང་སེམས་སྣང་བ་ཙམ། །

སེམས་ནི་ངོ་བོ་ཉིད་མྱིན་སྒྱུ་མ་བཞིན་། །

དེ་ཡང་སྤྲོས་པའི་མཐའ་དང་བྲལ་བ་ཡི། །

དབང་གྱིས་མཚོན་པའི་ལྟ་བ་རྟོགས་པར་ཤོག །

(ཕྱི་བསྐྱེད་རིམ་ནི།)
ཐོག་མེད་འཁོར་བའི་བག་ཆགས་ཀྱིས་བསླད་པའི་། །

མ་དག་འཁྲུལ་པའི་སྣོད་བཅུད་སྣང་བ་རྣམས། །

ཐབས་ལ་མཁས་པས་ལྷག་པའི་ལྷར་བསྒོམས་པས། །

རྟེན་དང་བརྟེན་པའི་འཁོར་ལོར་འཆར་བར་ཤོག །

(ནང་བསྐྱེད་རིམ་ནི།)
མ་བཅོས་ལྷུན་གྱིས་གྲུབ་པའི་ལུས་ཀྱི་རྩ། །

གདན་གསུམ་ཚང་བའི་སྐུ་རུ་བསྒོམས་པ་ཡིས། །

རྩ་རླུང་རྒྱལ་བས་བྱིན་གྱིས་བརླབས་བྱས་ནས། །

(བུམ་དབང་གྱི་ལྟ་བ་ནི།)

སྣང་སྟོང་ཟུང་འཇུག་ཡེ་ཤེས་སྐྱེ་བར་ཤོག །

གསང་དབང་གྱི་ལམ་རླུང་དང་གཏུམ་མོ།

སྣ་ཚོགས་ཀུན་རྟོག་སྐྱེད་བྱེད་ལས་ཀྱི་རླུང་། །

སྦྱོར་བ་བདུན་གྱི་དབང་དུ་བྱས་པ་ཡིས། །

གཏུམ་མོའི་མེ་དྲོད་ཕྱོགས་མེད་རབ་སྦར་ནས། །(ལྟ་བ་ནི། )

གསལ་སྟོང་ཟུང་འཇུག་ཡེ་ཤེས་སྐྱེ་བར་ཤོག །(གསུམ་པའི་ལམ་ནི)

ལས་ཀྱི་ཕྱག་རྒྱ་དངོས་སམ་ཡེ་ཤེས་ལ་། །

འདུ་ཤེས་གསུམ་ལྡན་སྦྱོར་བས་སྙོམས་ཞུགས་ནས། །

ཡས་བབས་དགའ་བ་བཞི་ཡྱི་རིམ་གྱིས་ནི། ། (ལྟ་བ་ནི།)

བདེ་སྟོང་ཟུང་འཇུག་ཡེ་ཤེས་སྐྱེ་བར་ཤོག ། (བཞི་པའི་ལམ་ནི།)

ལུས་དང་ངག་གྱི་རྦ་རླབས་དབང་གྱུར་ནས། །

ཏིང་འཛིན་སེམས་ཀྱི་རྦ་རླབས་གསུམ་བསྒོམས་པས། །

གཟུང་འཛིན་གཉིས་ཀྱི་རྦ་རླབས་རེངས་པ་ཡིས། ། (ལྟ་བ་ནི།)
བདེ་སྟོང་མཆོག་གྱི་ཡེ་ཤེས་སྐྱེ་བར་ཤོག །

(འདུས་པ་གསུམ་མཐར་ཕྱིན་ནས་འཕགས་པའི་ལམ་གྱི་མཚམས་སྦྱོར་ནི། )

དེ་ལྟར་རིམ་གཉིས་བསམ་གཏན་བསྒོམས་པ་ལས་། །

རང་ལུས་དག་ལ་ཉམས་གསུམ་སྐྱེས་པ་ཡིས། །

འདུས་པ་གསུམ་གྱི་ལམ་རྣམས་མཐར་ཕྱིན་ནས། །

པད་ཅན་ལུང་བསྟན་སྤྲུལ་སྐུའི་ཞལ་མཐོང་ཤོག །

(གྲུབ་མཐའ་སོགས་ཏེ་བླ་མ་ན་འཕོ་བ་ན། གྲུབ་མཐའ་རེ་རེ་ལ་། །བླ་མ་གང་ལ་། དབང་གང་བླང་། དཀྱིལ་འཁོར་གང་གནས་གྱུར། ཡོན་ཏན་གང་ཐོབ། གྲུབ་མཐའ་གང་སོགས་པ་སྡེ་ལྔ་ལྔ་ཡོད་པ་ལས། གྲུབ་མཐའ་དང་པོ་ལྔ་ནི། )

སྣ་ཚོགས་སྤྲུལ་སྐུར་དབང་བཞི་བླངས་པ་ཡིས། །

ཡན་ལག་བདུན་གྱི་རྩ་རྣམས་མངོན་གྱུར་ནས།
ཡོན་ཏན་བརྒྱ་ཕྲག་བདུན་གྱིས་བརྒྱན་པ་ཡི། །

འཁོར་འདས་དབྱེར་མེད་གྲུབ་མཐའ་སོགས་པར་ཤོག ། (གྲུབ་མཐའ་གཉིས་པའི་ལྔ་ནི།)

ཟུང་འཇུག་ལོངས་སྐུར་དབང་བཞི་བླངས་པ་ཡིས། །

ཡི་གེ་བྷ་གའི་དཀྱིལ་འཁོར་མངོན་གྱུར་ནས། །

རིགས་དྲུག་སོ་སོའི་སྐད་དུ་ཆོས་སྟོན་པའི། །

མ་འདྲེས་ཡོངས་རྫོགས་གྲུབ་མཐའ་སོགས་པར་ཤོག ། (གྲུབ་མཐའ་གསུམ་པའི་ལྔ་ནི།)

བདེ་ཆེན་ཆོས་སྐུར་དབང་བཞི་བླངས་པ་ཡིས། །

གསང་བ་བདུད་རྩིའི་དཀྱིལ་འཁོར་མངོན་གྱུར་ནས། །

ཉི་ཁྱི་ཆིག་སྟོང་རྒྱུ་བ་འགགས་པ་ཡིས། །

བདེ་སྟོང་ཆུང་ངུའི་གྲུབ་མཐའ་སོགས་པར་ཤོག །

(གྲུབ་མཐའ་བཞི་པའི་ལྔ་ནི།)

དབྱེར་མེད་སྐུ་ལས་དབང་བཞི་བླངས་པ་ཡིས། །

ཀུན་ཁྱབ་རླུང་གྱི་དཀྱིལ་འཁོར་མངོན་གྱུར་ནས། །

རྣམ་ཐར་གསུམ་གྱི་འབྲས་བུས་བརྒྱན་པ་ཡིས། །

བདེ་སྟོང་ཆེན་པོའི་གྲུབ་མཐའ་སོགས་པར་ཤོག །

(ཉེ་རྒྱུས་འབྲས་བུར་མཚམས་སྦྱོར་བ་ནི།)

བཅོ་གཉིས་ས་ཐོབ་ཕྱག་རྒྱའི་བྷ་གར་ནི། །

དུས་གསུམ་བདེ་གཤེགས་བཅུད་འདུས་ཐིག་ལེ་ལས་། །

འབྲས་དུས་དབང་གྱི་ཆུ་བོ་བླངས་པ་ཡིས། །

གཙུག་ཏོར་མཆོག་ཏུ་འགྲོས་བཞི་ཐིམ་པར་ཤོག །

(འབྲས་བུ་ལ་གསུམ་ལས། རང་དོན་གྱི་ཆེ་བ་ནི།)

རྟེན་དང་བརྟེན་པ་སྐུ་ལྔར་གནས་གྱུར་ཅིག །(གཞན་དོན་གྱི་ཆེ་བ་ནི། )

སྣ་ཚོགས་གདུལ་བྱའི་འདོད་རྒུའི་དཔལ་འབྱོར་སྤེལ། །(བདག་གཞན་གཉིས་ཀའི་ཆེ་བ་ནི། )

བདག་གཞན་མཉམ་དུ་མངོན་པར་འཚང་རྒྱ་བའི་། །

དཔག་ཡས་ཡོན་ཏན་ཚོགས་ལ་དབང་འབྱོར་ཤོག །

གོ་འཕང་མཆོག་དེ་མ་ཐོབ་དེ་སྲིད་དུ་། །

ཀུན་མཁྱེན་བླ་མའི་དྲུང་དུ་བདག་སྐྱེ་ཞིང་། །

ཉིད་ཐུགས་བརྩེ་བ་ཆེན་པོས་རྗེས་བཟུང་སྟེ་། །

ལམ་བཟང་འདི་དོན་བསྒོམས་པའི་སྐལ་ལྡན་ཤོག །

ཚེ་འདི་ཉིད་ལའང་འགལ་རྐྱེན་ཀུན་སྤོངས་ཤིང་། །

དམ་པས་བསྔགས་པའི་མཐུན་རྐྱེན་ཀུན་ཚང་ནས། །

མདོ་རྒྱུད་རྒྱ་མཚོའི་དགོངས་པ་མཐར་ཕྱིན་ནས། །

བདེ་གཤེགས་བསྟན་པ་ཕྱོགས་བཅུར་རྒྱས་བྱེད་ཤོག །

དྲིན་ཆེན་བླ་མ་རྣམས་ཀྱི་བྱིན་རླབས་དང་། །

སྐྱབས་ཆེན་དཀོན་མཆོག་གསུམ་གྱི་བདེན་པ་དང་། །

དཔལ་ཆེན་ཆོས་སྐྱོང་སྲུང་མའི་ནུས་མཐུ་ཡིས། །

རླབས་ཆེན་སྨོན་ལམ་འདི་དག་མྱུར་འགྲུབ་ཤོག ། (ཅེས་ལམ་འབྲས་བུ་དང་བཅས་པའི་ལམ་གྱི་རིམ་པ་རྣམས་རྒྱུད་ལ་སྐྱེ་བར་སྨོན་ལམ་འདེབས་པ་འདི་ནི་རྗེ་བཙུན་བླ་མ་རྣམས་ཀྱི་བྲན་དུ་གྱུར་པ་དགེ་སློང་རྒྱལ་ཁམས་པ་སེང་གེའི་མཐའ་ཅན་གྱིས་
སྦྱར་བའོ།། །།)
