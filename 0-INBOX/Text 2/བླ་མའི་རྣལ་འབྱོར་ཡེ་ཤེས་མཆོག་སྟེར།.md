(སྐྱབས་སེམས་ནི།) 

སྐྱབས་གནས་ཀུན་འདུས་ཧེ་རུ་ཀར། །

མི་ཕྱེད་གུས་པས་སྐྱབས་སུ་མཆི། །

སྲིད་འགྲོ་ཉམ་ངའི་གདུང་བ་ལས། །

བསལ་ཕྱིར་བླ་མེད་མཆོག་སེམས་བསྐྱེད། ། (ཡན་ལག་བདུན་ནི། )

དཔལ་ལྡན་བླ་མ་ཧེ་རུ་ཀར། །)

ཕྱག་འཚལ་མཆོད་འབུལ་སྡིག་པ་བཤགས། །

ཡི་རངས་བསྐུལ་ཞིང་གསོལ་བ་འདེབས། །

དགེ་ཚོགས་བྱང་ཆུབ་སྙིང་པོར་བསྔོ། ། (བགེགས་བསྐྲད་པ་ནི།) 

ཧཱུྃ། གདོད་ནས་འཁོར་འདས་གཉིས་མེད་ལ། །

བགེགས་དང་བར་ཆད་མིང་ཡང་མེད། །

གཟུང་འཛིན་རྣམ་པར་རྟོག་པའི་བགེགས། །

ཆོས་དབྱིངས་སྐྱེ་མེད་ཀློང་དུ་དེངས། (སུམ་བྷ་ནི། སྲུང་འཁོར་ནི།) 

ཧཱུྃ། འོད་གསལ་ཡེ་ཤེས་སྙིང་པོའི་རྩལ། །

དག་མཉམ་བདེ་བ་ཆེན་པོ་ལ། །

མཚན་འཛིན་འཁྲུལ་རྟོག་རང་སར་ཡལ། །

རིག་སྟོང་མཚམས་ལས་འདའ་མ་བྱེད། །བཛྲ་རཀྵཿ (བྱིན་འབེབས་ནི།) 

ཧཱུྃ། ཆོས་དབྱིངས་གཉུག་མའི་གཞལ་ཡས་ནས། །

དགོངས་བརྡ་སྙན་བརྒྱུད་རིག་འཛིན་ཚོགས། །

ཐུགས་དམ་བསྐུལ་ལོ་དབྱིངས་ནས་བཞེངས། །

གནས་འདིར་བྱིན་ཕོབ་དངོས་གྲུབ་སྩོལ། བཛྲ་ཨ་བེ་ཤ་ཡ་ཨཱཿ (མཆོད་རླབས་ནི།) 

ཧཱུྃ། སྟོང་ཉིད་དབྱིངས་ལས་སྙིང་རྗེའི་རྩལ། །

ཀུན་ཏུ་བཟང་པོའི་རྣམ་རོལ་སྤྲིན། །

ཆོས་དབྱིངས་རྒྱས་པར་འགེངས་བ་ཡིས། །

འཛད་མེད་ནམ་མཁའི་མཛོད་དུ་གྱུར། ཨོཾ་ཨཱཿཧཱུྃ་ཧོཿ (ཚོགས་ཞིང་བསྐྱེད་པ་ནི། )

ཨཱཿ ཆོས་རྣམས་རང་བཞིན་སྐྱེ་བ་མེད། །

འགག་མེད་རྩལ་ལས་སྣང་ཡུལ་ཀུན། །

དཔལ་རི་པདྨ་འོད་ཀྱི་ཞིང༌། །

ངོ་མཚར་བཀོད་པ་ལྷུན་གྲུབ་དབུས། །

གཞི་ལུས་རྡོ་རྗེ་རྣལ་འབྱོར་མ། །

དམར་གསལ་ཁྲོ་འཛུམ་སྒེག་པའི་ཉམས། །

ཕྱག་གཡས་ཐོད་རྔ་གཡོན་གྲི་གུག །

རུས་པའི་རྒྱན་དྲུག་དོར་སྟབས་ཅན། །

མདུན་མཁར་འཇའ་ཟེར་ཐིག་ལེའི་ཀློང༌། །

པདྨ་ཟླ་བ་རྒྱས་པའི་སྟེང༌། །

རྩ་བའི་བླ་མ་ཧེ་རུ་ཀ །

དམར་གསལ་ཁྲོ་འཛུམ་དགྱེས་པའི་ཉམས། །

ཕྱེད་སྐྱིལ་རུས་པའི་རྒྱན་དྲུག་སྤྲས། །

རྡོ་རྗེ་དྲིལ་བུས་ཕྱག་རྒྱ་སྒྱུར། །

ཐོད་སྐམ་དབུ་རྒྱན་སྟག་ཤམ་ཅན། །

སྤྱི་བོར་ཀུན་མཁྱེན་ངག་གི་དབང༌། །

བསྟན་པའི་ཉི་མ་ཆོས་ཀྱི་དབང༌། །

རྒྱལ་བའི་མྱུ་གུ་འཇིགས་མེད་གླིང༌།

གདོད་མའི་མགོན་པོ་ཀློང་ཆེན་པ། །

ཀུན་ཀྱང་ཧེ་རུ་ཀ་པའི་ཆས། །

རིག་རྩལ་རོལ་པ་ཐོགས་མེད་སྒྱུར། །

འཁོར་དུ་མདོ་སྒྱུ་སེམས་ཕྱོགས་དང༌། །

སྒྲུབ་སྡེ་བཀའ་བརྒྱད་ལ་སོགས་པའི། །

བརྒྱུད་གསུམ་རིག་འཛིན་བླ་མ་དང༌། །

ཡི་དམ་དཔའ་བོ་མཁའ་འགྲོ་དང༌། །

བཀའ་སྡོད་དམ་ཅན་སྤྲིན་ལྟར་འཁྲིགས། །

གནས་གསུམ་རྡོ་རྗེ་གསུམ་གྱིས་མཚན། །

དེ་ལས་འོད་ཟེར་རབ་འཕྲོས་པས། །

ཕྱོགས་བཅུ་དུས་བཞིའི་སྐྱབས་ཡུལ་ཀུན། །མདུན་མཁར་བཛྲ་ས་མཱ་ཛཿ (སྤྱན་འདྲེན་ནི།) 

ཧཱུྃ། བཞེངས་ཤིག་རིག་འཛིན་བླ་མའི་ཚོགས། །

དགོངས་ཤིག་དམ་ལྡན་བུ་ལ་དགོངས། །

གསང་གསུམ་བྱིན་ནུས་སྙིང་ལ་ཕོབ། །

ངོ་མཚར་རྟགས་མཚན་མྱུར་དུ་སྟོན། ཨེ་ཧྱ་ཧི་ཕེཾ་ཕེཾཿ (བཞུགས་གསོལ་ནི། )

ཧཱུྃ། དབྱིངས་ནས་སྤྱན་དྲངས་ཡེ་ཤེས་ལྷ། །

གཞི་རྒྱུད་རང་བཞིན་ལྷུན་གྲུབ་པའི། །

དཀྱིལ་འཁོར་ཆེན་པོར་རྟག་བཞུགས་ལ། 

དགོངས་པའི་རྩལ་ཆེན་སྙིང་ལ་སྦོར། ཛཿཧཱུྃ་བཾ་ཧོཿ (ཕྱག་འཚལ་ནི།) 

ཧཱུྃ། རང་དང་གཉིས་སུ་མེད་པའི་ལྷ། །

ཡེ་ནས་ཡེ་སངས་རྒྱས་པ་ལ། །

ཐ་དད་མཚོན་བྱའི་ཡུལ་ལས་འདས། །

དབྱེར་མེད་རྟོགས་པས་བརྡ་ཕྱག་འཚལ། །ན་མོ་ན་མ་ཧོཿ (མཆོད་པ་ནི།) 

ཧཱུྃ། ཚོགས་དྲུག་ཡུལ་གྱི་རྩལ་སྣང་ཀུན། །

ཀུན་ཏུ་བཟང་པོའི་རྒྱན་དུ་ཤར། །

འདོད་ཡོན་མ་སྤངས་ཕྱག་རྒྱ་ཆེ། །

བླང་དོར་འཛིན་ཞཻན་བྲལ་བས་མཆོད། བཛྲ་ཨརྒྷཾ༴ ཤབྡ་པཉྩ་རཀྟ་བྷ་ལིཾ་ཏ་ཁཱ་ཧིཿ (བསྟོད་པ་ནི།) 

ཧཱུྃ། གདོད་མའི་མགོན་པོའི་ཡེ་ཤེས་རྩལ། །

དགོངས་བརྡ་སྙན་བརྒྱུད་སྤྲུལ་བའི་གར། །

སྣ་ཚོགས་སྣང་ཡང་ངོ་བོར་གཅིག 

ཡེ་ཤེས་སྒྱུ་འཕྲུལ་དྲྭ་བར་བསྟོད། ཛཔྲ་ནི། 

ཐུགས་ཀར་སྐྱེ་མེད་འོད་གསལ་ཀློང༌། །

རང་བྱུང་རྡོ་རྗེའི་འབྲུ་དྲུག་ཤར། །

བློ་འདས་ཆོས་སྐུའི་དགོངས་པ་ལ། །

ཅོག་བཞག་ཆེན་པོའི་ངང་ནས་བཟླ། འ་ཨ་ཧ་ཤ་ས་མཿ བཟླས་པའི་ཚད་ནི་བྱེ་བ་བཅུ། འབྲིང་ལ་བྱེ་བ། ཐམས་ཡ། (རྗེས་ལ་ཚོགས་བྱིན་རླབས་ནི།) 

ཧཱུྃ། ཡེ་ཤེས་རྩལ་ལས་རཾ་ཡཾ་ཁཾ། །

འཕྲོས་པས་མ་དག་དངོས་འཛིན་སྦྱངས། །

བརྟན་གཡོའི་འཇིག་རྟེན་མ་ལུས་པ། །

ཡེ་ཤེས་ཚོགས་ཀྱི་རོལ་པར་གྱུར། །ཨོཾ་ཨཱཿཧཱུྃ་ཧོཿ(སྤྱན་འདྲེན་ནི།) 

ཧཱུྃ། དབྱིངས་ན་བཞུགས་པ་ཆོས་ཀྱི་སྐུ། །

གཟུགས་སྐུ་ཡེ་ཤེས་འཁོར་ལོའི་སྤྲིན། །

གང་འདུལ་གདུལ་བྱའི་ངཽར་སྣང་བའི། །

སྲས་བཅས་རྒྱལ་བའི་ཚོགས་རྣམས་གཤེགས། །

བཛྲ་ས་མཱ་ཛཿ (མཆོད་པ་ནི། )

ཧཱུྃ། དགྱེས་མཉམ་མཆོག་གི་མཆོད་པ་ནི། །

ཡེ་ཤེས་ཆེན་པོའི་བཅུད་དུ་སྨིན། །

གསང་གསུམ་རྡོ་རྗེའི་ཕྱག་རྒྱ་ཆེ། །

བསལ་བཞག་བྲལ་བའི་ངང་དུ་བཞེས། །ག་ཎ་ཙཀྲ་པཱུ་ཛ་ཧོཿ (བཤགས་པ་ནི།) 

མ་རིག་གཟུང་འཛིན་རླབས་ཀྱི་གཡོས། །

རང་གནས་ཡེ་ཤེས་རང་ཞལ་བསྒྲིབས། །

གློ་བུར་བག་ཆགས་སེམས་དང་བཅས། །

གཞི་གྲོལ་ཆོས་དབྱིངས་ཀློང་དུ་བཤགས། བཛྲ་ས་མ་ཡ་ཨཱཿ (བསྒྲལ་བསྟབ་ནི། )

ཚོགས་བརྒྱད་རྟོག་པའི་འཁྲུལ་འཁོར་ཀུན། །

བློ་འདས་འོད་གསལ་དབྱིངས་སུ་བསྒྲལ། 

ཁྱད་ཆོས་དྲུག་ལྡན་ཧེ་རུ་ཀའི། །

ཐིག་ལེ་ཉག་ཅིག་ཀློང་དུ་བསྟབ། །རཱུ་ཏྲ་སརྦ་ཧ་ལ་པཉྩ་པཱུ་ཛ་ཁཱ་ཧིཿ (ལྷག་མ་ནི།) 

ཧཱུྃ། རབ་འབྱམས་དཀྱིལ་འཁོར་མཐའ་སྐྱོང་བ། །

དབང་ཕྱུག་མཁའ་འགྲོ་གིང་ལངྐ། །

འབར་མ་མ་སྲིང་ས་བདག་སོགས། །

ལྷག་གཏོར་འདི་བཞེས་ཕྲིན་ལས་སྒྲུབས། ཨུཙྪིཥྚ་བ་ལིངྟ་ཁཱ་ཧིཿ (བསྐུལ་པ་ནི།) 

ཧཱུྃ། མ་གཡེལ་བླ་མ་ཧེ་རུ་ཀ །

བདག་ཅག་མོས་པའི་བུ་ལ་དགོངས། །

ཐུགས་རྗེའི་མཐུ་རྩལ་སྟོབས་བསྐྱེད་ལ། །

བྱིན་རླབས་ཡེ་ཤེས་སྙིང་ལ་ཕོབ། ཆད་ཐོ་ནི། ཧཱུྃ། 

སྔོན་ཚེ་རྒྱལ་བའི་སྤྱན་སྔ་རུ། །

བསྟན་པ་བསྲུང་བར་ཞལ་བཞེས་པའི། །

མ་མགོན་གཟའ་རྡོར་དྲེགས་པའི་ཚོགས། །

མཆོད་གཏོར་འདི་བཞེས་ཕྲིན་ལས་སྒྲུབས། (བརྟན་མ་ནི།) 

ཧཱུྃ། པདྨའི་བཀའ་སྡོད་བོད་ཁམས་སྐྱོང༌། །

ཚེ་རིང་མ་སོགས་བརྟན་མའི་ཚོགས། །

བཤལ་ཆུའི་གཏོར་མ་འདི་ལོངས་ལ། །

མཐའ་དམག་གདུག་པའི་འཚེ་བ་སྲུངས། མ་མ་ཧྲིང་ཧྲིང་བ་ལིངྟ་ཁཱ་ཧིཿ (རྟ་བྲོ་ནི། )

ཧཱུྃ། གཟུང་འཛིན་འཁྲུལ་པའི་རྣམ་རྟོག་ཀུན། །

གཞི་རྫོགས་བར་མཚམས་མེད་པར་མནན། །

འོད་གསལ་གཉུག་མའི་རྒྱ་ཡིས་ཐེབས། །

བློ་འདས་དགོངས་པའི་ས་ལ་སྐྱོལ། སྟྭཾ་བྷ་ཡ་ནན། (མཆོད་ཅིང་བསྟོད་ལ་དངོས་གྲུབ་བླང་བ་ནི།)

ཧོ། རིག་འཛིན་སྒྱུ་འཕྲུལ་དྲྭ་བའི་དབྱིངས། །

ཐུགས་རྗེས་དགོངས་པའི་རྩལ་ཕྱུང་ལ། །

སྣང་བ་བཞི་ཡི་འོད་གསལ་སྤྲིན། །

ཚེ་འདི་ཉིད་ལ་མཐར་ཕྱིན་མཛོད། །མ་ཧཱ་སུ་ཁ་སིདྡྷི་ཧོཿ (བཤགས་པ་ནི།) 

ཧཱུྃ། ཀ་དག་ཆོས་ཟད་དགོངས་པ་ལ། །

ཚོགས་བརྒྱད་འཁྲུལ་པའི་ཉེས་ཚོགས་ཀུན། །

འོད་གསལ་དབྱིངས་སུ་དག་ནས་ཀྱང༌། །

དགོངས་པའི་ཡེ་ཤེས་མངོན་གྱུར་མཛོད། །ཡིག་བརྒྱ་བརྗོད། (བསྡུ་ལྡང་ནི།) 

ཧོ། གཞི་སྣང་ལྷུན་གྲུབ་རོལ་པའི་རྩལ། །

གཞི་དབྱིངས་གཉུག་མའི་དབྱིངས་སུ་ཐིམ། 

མ་འགགས་ཐུགས་རྗེའི་རོལ་པ་ལས། །

རྣམ་གྲོལ་གཟུགས་སྐུའི་རོལ་པར་ཤར། (བསྔོ་སྨོན་ནི།) 

ཧོ། ཟག་བཅས་ཟག་མེད་དགེ་རྩ་ཀུན། 

གཞོན་དུ་བུམ་སྐུའི་ཀློང་དུ་བསྔོ། །

འཁྲུལ་པའི་རྫུན་རིས་དབྱིངས་སུ་ནུབ། 

འཁོར་བ་དོང་ནས་སྤྲུགས་གྱུར་ཅིག །(བཀྲ་ཤིས་ནི།) 

ཧོ། བླ་མའི་བྱིན་རླབས་སྤྲིན་ལྟར་འཁྲིགས། །

ཡི་དམ་དངོས་གྲུབ་ཆར་ཆེན་འབེབས། །

མཁའ་འགྲོས་བུ་བཞིན་བསྐྱངས་ནས་ཀྱང༌། །

མཆོག་ཐུན་གྲུབ་པའི་བཀྲ་ཤིས་ཤོག (ཅེས་པའང་སྨྲར་བཙུན་ཟུང་དང་ནི་གུ་བཅས་ཀྱི་ངོར་དཔལ་ཆེན་འདུས་པས་བྲིས་པ་དགེ་ལེགས་འཕེལ།། བཀྲ་ཤིས།།)
