# ༄༅། གུ་རུ་ཐོལ་ཤགས།

༈ ཨེ་མ་ཧོཿ
ཆོས་ཀྱི་དབྱིངས་ནས་བཞུགས་པའི་དཀོན་མཆོག་གསུམཿ
ཁྱེད་ཅག་རྣམས་ནི་རྣམ་དག་དྲི་མ་མེདཿ
བདག་སོགས་རྣམས་ནི་བློ་བུར་དྲི་མས་བསྒྲིབསཿ
བློ་བུར་དྲི་མས་བསྒྲིབས་པ་མཐོལ་ལོ་བཤགསཿ
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

བླ་མ་སངས་རྒྱས་ཡིན་པ་ངོ་མ་ཤེསཿ
གདམས་ངག་བདུད་རྩི་ཡིན་པ་དོན་མ་རྟོགསཿ
བླ་མ་ལ་མོས་གུས་ཆུང་བ་མཐོལ་ལོ་བཤགསཿ
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

རང་ལུས་ལྷ་ཁང་ཡིན་པ་ངོ་མ་ཤེསཿ
སངས་རྒྱས་ནང་ན་བཞུགས་པ་དོན་མ་རྟོགསཿ
སྒྱུ་ལུས་བྲན་དུ་བཀོལ་བ་མཐོལ་ལོ་བཤགསཿ
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

བཟའ་གཏུང་ཚོགས་འཁོར་ཡིན་པ་ངོ་མ་ཤེསཿ
མཁའ་འགྲོ་ཚོགས་ལ་མཉེས་པ་དོན་མ་རྟོགསཿ
ཚོགས་ཕུད་མཐའ་ནས་ཉམས་པ་མཐོལ་ལོ་བཤགསཿ
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

ཆོས་གྲོགས་སློབ་དཔོན་ཡིན་པ་ངོ་མ་ཤེསཿ
དམ་ཚིག་སྒྲོན་མེ་ཡིན་པ་དོན་མ་རྟོགསཿ
ཆོས་གྲོགས་དམ་ཚིག་ཉམས་པ་མཐོལ་ལོ་བཤགསཿ
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

འགྲོ་དྲུག་ཕ་མ་ཡིན་པ་ངོ་མ་ཤེསཿ
ཕ་མའི་དྲིན་ལན་མ་འཇལ་དོན་མ་རྟོགསཿ
ཁ་ངན་ཚིག་ངན་ཤོར་བ་མཐོལ་ལོ་བཤགསཿ
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

ཕྱིན་ཚད་སྐོར་བ་ཡིན་པ་ངོ་མ་ཤེསཿ
སྐོར་བས་མཚན་ཉིད་མ་ཤེས་དོན་མ་རྟོགས།།
ལུང་སྟོང་རྗེས་ཀྱིས་བཀང་བ་མཐོལ་ལོ་བཤགས་ཿ
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

ཚེ་འདི་སྐྱེ་བ་ཡིན་པ་ངོ་མ་ཤེས།།
སྐྱེས་ནས་འཆི་བ་ཡིན་པ་དོན་མ་རྟོགས།།
མི་ཚེ་གཡང་ལ་ལྟུང་བ་མཐོ་ལོ་བཤགས།།
ཨོ་རྒྱན་རིན་པོ་ཆེ་ལ་གསོལ་བ་འདེབསཿ
གུ་རུ་ཐུགས་རྗེ་ཅན་ལ་གསོལ་བ་འདེབསཿ
ལས་ངན་སྡིག་སྒྲིབ་དག་པར་བྱིན་གྱིས་རློབསཿ

གནས་མཆོག་འདི་ནི་ཟངས་མདོག་དཔལ་རེའི་རྩེརཿ
རུ་ཏྲ་ཕོ་མོ་བརྫེས་པའི་སྟེང་དུཿ
ཨོ་རྒྱན་དུས་གསུམ་སངས་རྒྱས་བཞུགས་པའི་དྲུངཿ
བདག་ཅག་མཁའ་འགྲོ་སྡེ་ལྔའི་མཐོལ་བཤགས་འབུལཿ
མཏོ་ལོ་བཤགས་སོ་ཚངས་པའི་དངོས་གྲུབ་སྩལཿ
ཙངས་པའི་དོན་གྱི་དངོས་གྲུབ་སྩལ་དུ་གསོལཿ
རྐྱེན་ངན་ཕྱི་ཡི་བར་ཆད་ཕྱི་རུ་གསོལཿ
རྐྱེན་ངན་ནང་གི་བར་ཆད་ནང་དུ་གསོལཿ
རྐྱེན་ངན་གསང་བའི་བར་ཆད་དབྱིངས་སུ་གསོལཿ
མཆོག་དང་མཐུན་མོང་དངོས་གྲུབ་སྩལ་དུ་གསོལ༔

ཨོཾ་ཨཱཿཧཱུྃ་བཛྲ་གུ་རུ་པདྨ་སིདྡྷི་ཧཱུྃ༔

༈ ཨེ་མ་ཧོཿ
མཆོག་གསུམ་ངོ་བོ་རིག་འཛིན་ཚོགས་ཀྱི་རྗེ། །
སྤྲུལ་སྐྱེས་མཆོག་འགྲོ་བ་ཡོངས་ཀྱི་མགོན། །
ཐུགས་རྗེའི་མངའ་བདག་ཨུ་རྒྱན་རིན་པོ་ཆེ། །
བོད་འབངས་སྡུག་པའི་སེམས་ཅན་སྐྱབས་ཏུ་གསོལ།།

མ་རུངས་ལས་ཀྱི་མནར་བའི་འགྲོ་བ་རྣམས། །
དུས་ངན་འདི་ན་བདེ་བའི་གོ་སྐབས་མེད། །
ད་ནེ་ཁྱེད་ཀྱི་ཐུགས་རྗེས་མ་བསྐྱབ་ན། །
གཞན་པའི་ར་མདའ་མ་མཆིས་བརྩེ་བས་གཟིགས།།

བདག་སོགས་མོས་པའི་བུ་སློབ་ཐམས་ཅད་ཀྱི། །
གསང་སྔགས་བསྒྲུབ་པའི་བར་ཆད་ཞི་བ་དང། །
མཆོག་དང་མཐུན་མོང་དངོས་གྲུབ་ཚེ་འདི་ལ། །
ཐུབ་ནས་ཁྱེད་རང་ལྟ་བུར་བྱིན་གྱིས་རློབས།།

མཆོག་གསུམ་ཀུན་འདུས་ཨུ་རྒྱན་རིན་པོ་ཆེ།།
གནས་ལྔ་རིག་པའི་པན་ཆེན་པདྨ་དཀར།།
སྙིང་པའི་བསྟན་འཛིན་དག་དབང་བཟང་པོ་དང་།།
དཔག་བསམ་དབང་པོ་གྲུབ་དབང་རིན་པོ་ཆེ།།
བཀའ་དྲིན་འཁོར་མེད་རྩ་བའི་བླ་མ་ལ།།
གསོལ་བ་འདེབས་སོ་བདག་བརྒྱུད་བྱིན་གྱིས་བརློབས།།

ཚེ་འདིར་བསམ་པའི་དོན་ཀུན་འགྲུབ་པ་དང། །
གཏན་བདེ་མཆོག་གི་དངོས་གྲུབ་སྩལ་དུ་གསོལ།

ཨོཾ་ཨཱཿ ཧཱུྃ་བཛྲ་གུ་རུ་པདྨ་སིདྡྷི་ཧཱུྃ 
ཅི་འགྲུབ་བཟླས།

༈ ཨེ་མ་ཧོཿ
གནས་འཛམ་གླིང་ལྷོ་ནུབ་སྲིན་པོའི་ཡུལ། །
རྔ་ཡབ་ཞེས་ཟངས་མདོག་དཔལ་རིའི་རྩེར། །
དཔལ་པདྨ་འོད་ཀྱི་གཞལ་ཡས་ཁང༌། །
དཔེ་མཚུངས་བྲལ་སྤྲུལ་པའི་ཕོ་བྲང་དབུས། །
རྗེ་པད་འབྱུང་རཀྴ་ཐོད་འཕྲེང་རྩལ། །
འཁོར་རིག་འཛིན་མཁའ་འགྲོ་བྱེ་བས་བསྐོར། །
དྲན་ཆོས་སྐྱོང་དྲེགས་པ་སྡེ་བརྒྱད་འགྱེད། །
ངོ་མཚར་བའི་བཀོད་པ་བསམ་མི་ཁྱབ། །
མི་བདག་ཀྱ་འདེ་ནས་ཚེ་འཕོས་ནས། །
ལུས་སྐྱེ་སྲིད་གཞན་དུ་མ་བརྒྱུད་པར། །
གནས་དེ་རུ་མདའ་འཕང་བཞིན་བསྒྲོད་དེ། །
