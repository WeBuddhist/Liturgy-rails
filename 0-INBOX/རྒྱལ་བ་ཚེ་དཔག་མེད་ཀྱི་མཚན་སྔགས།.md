# ༄༅། །རྒྱལ་བ་ཚེ་དཔག་མེད་ཀྱི་མཚན་སྔགས།

འཇིག་རྟེན་འདྲེན་པའི་གཙོ་བོ་ཚེ་དཔག་མེད། །
དུས་མིན་འཆི་བ་མ་ལུས་འཇོམས་མཛད་པ། །
མགོན་མེད་སྡུག་བསྔལ་གྱུར་པ་རྣམས་ཀྱི་སྐྱབས། །
སངས་རྒྱས་ཚེ་དཔག་མེད་ལ་ཕྱག་འཚལ་ལོ། །

ཨོཾ་ཨ་མ་ར་ཎི་ཛཱི་ཝཱནྟི་ཡེ་སྭཱཧཱ།

དུས་མིན་འཆི་བའི་མཚན་མ་མཐོང་བ་ན། །
དེ་ཡི་མོད་ལ་ཚེ་དཔག་མེད་མགོན་སྐུ། །
གསལ་བར་མཐོང་ནས་འཆི་བདག་དཔའ་བཅོམ་སྟེ། །
འཆི་མེད་རིག་འཛིན་མྱུར་དུ་འཐོབ་པར་ཤོག །
