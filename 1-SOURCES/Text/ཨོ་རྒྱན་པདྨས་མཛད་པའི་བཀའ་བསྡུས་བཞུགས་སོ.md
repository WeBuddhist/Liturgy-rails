# ༄༅། །ཨོ་རྒྱན་པདྨས་མཛད་པའི་བཀའ་བསྡུས་བཞུགས་སོ། ^0

## 0. ཀླད་ཀྱི་དོན། ^I-0

### སངས་རྒྱས་ཆོས་དང་དགེ་འདུན་ལ་རྟག་ཏུ་གུས་པས་ཕྱག་འཚལ་ལོ ^I-1-0

ཨྱོན་སྐད་དུ༔ ^I-1-1

བུདྡྷ་དྷརྨ་སཾ་གྷ་ཡ༔ ^I-1-2

བོད་སྐད་དུ༔ ^I-1-3

སངས་རྒྱས་ཆོས་དང་དགེ་འདུན་ལ༔ ^I-1-4

རྟག་ཏུ་གུས་པས་ཕྱག་འཚལ་ལོ༔ ^I-1-5

འདྲེན་པའི་སྐྱེས་བུ་པདྨ་འབྱུང་གནས་ཀྱི༔ ^I-1-6

གདུལ་བྱའི་དོན་དུ་འཁྲུང་རབས་འདི་བསྟན་པས༔ ^I-1-7

སྐལ་ལྡན་དོན་དུ་ཤེས་ལྡན་དད་པས་སྐྱོབ༔ ^I-1-8

### རྒྱལ་སྲས་མུ་ཁྲི་བཙན་པོས་རྣམ་ཐར་མདོར་བསྡུས་གསུང་བར་ཞུས་པ ^I-2-0

ཨེ་མ་ཧོ༔ ^I-2-1

དེ་ནས་རྒྱལ་སྲས་མུ་ཁྲི་བཙན་པོ་ཡིས༔
དབུ་རྩེ་རིགས་གསུམ་སློབ་དཔོན་སྤྱན་དྲངས་ནས༔
ཟ་འོག་དགུ་བརྩེགས་ཁྲི་ལ་སློབ་དཔོན་བཞུགས༔
ཟ་འོག་ལྔ་བརྩེགས་ཁྲི་ལ་མཁན་པོ་བཞུགས༔ ^I-2-2

གཡས་གྲལ་གཡོན་བྲལ་གཡོན་གྲལ་གབ་རྩེའི་གདན་སྟེང་ནས༔ ^I-2-3

བེེ་རོས་གཙོ་བྱས་ལོ་ཙྭ་རྣམ་གསུམ་བཞུགས༔ ^I-2-4

ནོར་སྣ་ཁྱད་འཕགས་མང་པོ་ཕུལ་ནས་སུ༔ ^I-2-5

ཕྱག་སྟེ་མང་དུ་བཙལ་ནས་ཞུས་པ་ནི༔ ^I-2-6

ཨེ་མ་ཧོ༔ ^I-2-7

དུས་གསུམ་མཁྱེན་པའི་རྒྱལ་སྲས་ཆེན་པོ་ལགས༔
ཡབ་རྗེ་ཁྲི་སྲོང་ལྡེའུ་བཙན་དགུང་དུ་གཤེགས༔
བསྟན་པའི་སྒྲོན་མེ་སྲིན་པོའི་ཡུལ་དུ་གཤེགས༔
བོད་ཀྱི་མི་རྣམས་ཚེ་ཐུང་གཡེང་བས་ཁེངས༔ ^I-2-8

འདི་ནས་བཟུང་སྟེ་བསྐལ་བ་ཐ་མའི་བར༔
སྐལ་ལྡན་དོན་དུ་དམ་ཆོས་དོན་འདུས་པ༔ ^I-2-9

གུ་རུ་ཉིད་ལ་གསོལ་བ་གསོལ་བ་འདེབས་ནུས་པའི༔ ^I-2-10

ཁྱེད་ཀྱིས་རྣམ་ཐར་མདོར་བསྡུས་གསུང་བར་ཞུ༔
དེ་སྐད་གསུང་པས་གུ་རུས་བཀའ་བསྩལ་པ༔
ལེགས་པར་ཉོན་ཅིག་མུ་ཁྲི་བཙན་པོ་ཁྱོད༔
མ་འོངས་དོན་དུ་བདག་གིས་མདོར་བསྡུས་བསྟན༔ ^I-2-11

ཨེ་མ་ཧོ༔ ^I-2-12

སྐྱེས་པའི་ཡབ་བརྒྱད་བལྟམས་པའིཡུམ་བརྒྱད་དང་༔
སྤྲུལ་བའི་སྲས་བརྒྱད་བྱོན་པའི་ཡུལ་བརྒྱད་དང་༔
བཞུགས་པའི་གནས་བརྒྱད་བསྟེན་པའི་བླ་མ་བརྒྱད༔
ཞལ་གཟིགས་ཡི་དམ་མཐར་ཕྱིན་གྲུབ་རྟགས་བརྒྱད༔ ^I-2-13

དུར་ཁྲོད་བརྒྱད་དང་ཆོས་བརྒྱུད་སློབ་མ་བརྒྱད༔
དབེན་གནས་བརྒྱད་དང་ཐུགས་བྱོན་ཇོ་མོ་བརྒྱད༔
མཛད་འཕྲིན་བརྒྱད་དང་སྦས་པའི་གཏེར་ཁ་བརྒྱད༔ ^I-2-14

ཉམས་ལེན་ཟབ་ཆོས་བརྒྱད་དང་ཆོས་བདག་གླིང་པ་རྣམས་ཡོད༔ ^I-2-15

## 1. གུ་རུ་མཚན་བརྒྱད་བྱོན་ཚུལ ^1-0

ཨེ་མ་ཧོ༔ ^1-1

དང་པོ་གུ་རུ་མཚན་བརྒྱད་བྱོན་ཚུལ་ནི༔ ^1-2

ཁམས་གསུམ་སེམས་ཅན་བདེ་ལ་བཀོད༔ ^1-3

གུ་རུ་པདྨ་འབྱུང་གནས་ཡིན༔ ^1-4

བསྟན་པའི་མངའ་བདག་ཆོས་ཀྱི་རྗེ༔ ^1-5

གུ་རུ་པདྨ་སཾ་བྷ་ཡིན༔ ^1-6

སྐྱོན་གྱིས་མ་གོས་སྡེ་སྣོད་འཛིན༔ ^1-7

གུ་རུ་པདྨ་རྒྱལ་པོ་ཡིན༔ ^1-8

བདེ་བ་ཐམས་ཅད་སྐུ་ལ་རྫོགས༔ ^1-9

གུ་རུ་རྡོ་རྗེ་གྲོ་ལོད་ཡིན༔ ^1-10

ཐེག་དགུའི་མཉམ་ཉིད་ནམ་མཁར་བརྡལ༔ ^1-11

གུ་རུ་ཉི་མ་འོད་ཟེར་ཡིན༔ ^1-12

སྐུ་ལུས་གཅིག་ལ་བཀོད་པ་བརྒྱད༔ ^1-13

གུ་རུ་ཤྰཀྱ་སེངྒེ་ཡིན༔ ^1-14

རིགས་དྲུག་ཀུན་ལ་ཆོས་སྒྲ་སྒྲོག༔ ^1-15

གུ་རུ་སེངྒེ་སྒྲ་སྒྲོག་ཡིན༔ ^1-16

ཤེས་བྱ་ཐམས་ཅད་མཁྱེན་མཛད་པའི༔ ^1-17

གུ་རུ་བློ་ལྡན་མཆོག་སྲེད་ཡིན༔ ^1-18

གུ་རུ་མཚན་བརྒྱད་ཀྱི་ལེའུ་སྟེ་དང་པོའོ༔ ^1-19

## 2. སྐྱེས་པའི་ཡབ་བརྒྱད་བསྟན་པ ^2-0

ཨེ་མ་ཧོ༔ ^2-1

གཉིས་པ་སྐྱེས་པའི་ཡབ་བརྒྱད་བསྟན་པ་ནི༔ ^2-2

དབྱིངས་རིག་རྣམ་པར་ཤེས་པའི་ཡབ༔ ^2-3

ཆོས་སྐུ་ཀུན་ཏུ་བཟང་པོ་ཡིན༔ ^2-4

སྐྱེ་འཆི་བསྟན་གཉིས་སྤངས་པའི་ཡབ༔ ^2-5

མགོན་པོ་ཚེ་དཔག་མེད་པ་ཡིན༔ ^2-6

རིགས་དྲུག་འཕགས་པ་ཀུན་གྱིས་ཡབ༔ ^2-7

སངས་རྒྱས་སྣང་བ་མཐའ་ཡས་ཡིན༔ ^2-8

ཆོས་ཀྱི་རྩ་བ་བྱང་སེམས་ཡབ༔ ^2-9

ལོངས་སྐུ་ཐུགས་རྗེ་ཆེན་པོ་ཡིན༔ ^2-10

བསྟན་པའི་གཞི་མ་དགེ་འདུན་ཡབ༔ ^2-11

སྤྲུལ་སྐུ་ཤྰཀྱ་ཐུབ་པ་ཡིན༔ ^2-12

རུས་པ་ཆེ་བ་རྒྱལ་པོའི་ཡབ༔ ^2-13

རྒྱལ་པོ་ཨིནྡྲ་བོ་དྷི་ཡིན༔ ^2-14

མཇལ་བ་སྔ་བ་མི་ཡི་ཡབ༔ ^2-15

ཆོས་བློན་ཏྲི་ན་འཛིན་པ་ཡིན༔ ^2-16

བརྩེ་བས་གྲོས་བཏབ་གྲོགས་ཀྱིས་ཡབ༔ ^2-17

གྲོགས་པོ་གསེར་འོད་དམ་པ་ཡིན༔ ^2-18

སྐྱེས་པའི་ཡབ་བརྒྱད་ཀྱི་ལེའུ་སྟེ་གཉིས་པའོ༔ ^2-19

## 3. བལྟམས་པའི་ཡུམ་བརྒྱད་བསྟན་པ ^3-0

ཨེ་མ་ཧོ༔ ^3-1

གསུམ་པ་བལྟམས་པའི་ཡུམ་བརྒྱད་བསྟན་པ་ནི༔ ^3-2

དྷ་ན་ཀོ་ཤ་རྒྱ་མཚོའི་ཡུམ༔ ^3-3

པདྨ་གེ་སར་སྡང་བོ་ཡིན༔ ^3-4

སྤྱིར་ཡང་མ་གྲུབ་བདེ་ཆེན་ཡུམ༔ ^3-5

ཟག་མེད་ཀུན་ཏུ་བཟང་མོ་ཡིན༔ ^3-6

སྤྲུལ་པའི་སྐུ་ལ་བསྟོད་པའི་ཡུམ༔ ^3-7

རྡོ་རྗེ་རྣལ་འབྱོར་མ་ཉིད་ཡིན༔ ^3-8

བདག་འཛིན་སྲི་ཞུ་བཙན་པའི་ཡུམ༔ ^3-9

བཙུན་མོ་འོད་འཆང་ལྷ་མོ་ཡིན༔ ^3-10

དུར་ཁྲོད་བརྟུལ་ཞུགས་མཛད་པའི་ཡུམ༔ ^3-11

དཔལ་ལྡན་རྡོ་རྗེ་ཕག་མོ་ཡིན༔ ^3-12

དབང་བཞི་རྫོགས་པར་བསྐུར་བའི་ཡུམ༔ ^3-13

དགེ་སློང་ཀུན་དགའ་སྨོན་ལམ་ཡིན༔ ^3-14

བཀའ་ཡི་གཉེར་བྱང་གཏད་པའི་ཡུམ༔ ^3-15

མཁའ་འགྲོ་ལས་ཀྱི་དབང་མོ་ཡིན༔ ^3-16

བསྟན་པའི་སྲོག་ཤིང་བཙུགས་པའི་ཡུམ༔ ^3-17

རྗེ་བཙུན་འཕགས་མ་སྒྲོལ་མ་ཡིན༔ ^3-18

བལྟམས་པའི་ཡུམ་བརྒྱད་ཀྱི་ལེའུ་སྟེ་གསུམ་པའོ༔ ^3-19

## 4. སྤྲུལ་པའི་སྲས་བརྒྱད་བསྟན་པ ^4-0
